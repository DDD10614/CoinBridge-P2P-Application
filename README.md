# CoinBridge P2P – Cryptocurrency Trading Application

## Project Overview

CoinBridge P2P is an AI-enabled peer-to-peer cryptocurrency trading application prototype designed to support secure INR–USDT trading workflows, customer identity verification, payment verification, transaction monitoring, and fraud-risk management.

The project explores how technology and AI-assisted risk controls can improve transparency, security, and trust in peer-to-peer cryptocurrency transactions.

## Key Application Features

### 1. User Authentication
- User registration and sign-in interface
- Form validation
- User and admin interface roles

### 2. User Dashboard
- Wallet balance overview
- Recent transaction activity
- Quick access to buy, sell, deposit, and withdrawal screens

### 3. P2P Marketplace
- Buy and sell USDT offers
- Price and transaction limits
- Payment method information
- Order details and payment timer

### 4. KYC and Bank Verification
- Identity submission interface
- Bank-account linking workflow
- Verification status interface

### 5. Payment and Escrow Workflow
- Buyer payment confirmation
- Simulated escrow transaction flow
- Seller confirmation and simulated asset release

### 6. Transaction History and Dispute Management
- Transaction status tracking
- Order history
- Dispute submission interface

### 7. Admin and Risk Management
- Flagged transaction review
- User verification queue
- Dispute management interface
- Rule-based risk indicators

## Project Objectives

- Explore secure P2P cryptocurrency trading workflows.
- Improve customer onboarding and verification processes.
- Reduce exposure to third-party payment fraud.
- Support transaction monitoring and risk assessment.
- Provide transparent transaction and dispute workflows.

## Project Status and Limitations

This project is an academic application prototype, not a production-ready cryptocurrency exchange.

- User accounts and transactions use demo data.
- Authentication is not production-grade.
- KYC and bank-account verification are simulated; no live verification provider is connected.
- Escrow is simulated; no real funds are held.
- No live blockchain network or external wallet integration is connected.
- No production backend or database is implemented.
- Security, load and production-readiness testing have not been established.

## Disclaimer

This application is developed for academic, demonstration, and portfolio purposes. It does not provide live cryptocurrency trading, banking, payment processing, or regulated financial services. All transactions, balances, verification and escrow activities shown in the prototype are simulated.

Any real-world implementation would require appropriate legal, regulatory, security, banking and compliance approvals.
